# Changelog

## 0.1.0 - 2026-10-21

- Add local WebGL/Canvas mapping workbench with 3D terrain/cloud, relief/coverage, cross-section and cell inspection.
- Implement bounded CSV/JSONL/ASCII PLY, concept raw-ToF adapter and NWP1 UDP snapshots.
- Add external sensor-pose registration, median-cell terrain, conservative MAD rejection, slopes and contour segments.
- Export full accepted point data, numerical grids, north-up images, local contours and provenance bundles.
- Document scientific methods, data contracts, limits, validation and hardware integration roadmap.
- Add synthetic multiresolution experiment, committed results, 25 tests and Python CI matrix.
