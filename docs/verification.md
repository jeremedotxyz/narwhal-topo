# Verification record

Version 0.1.0, 21 October 2026. **25 automated tests passed locally**, including actual localhost HTTP and UDP integration. GitHub Actions is configured for Python 3.10 and 3.12; consult the run result before treating CI as verified.

## Automated evidence

- Independently defined plane heights and slope agree with the expected finite differences.
- Missing cells remain unsupported, and adjacent slope/contour computations do not fill gaps.
- Point support, robust spike rejection, validity filtering and resource bounds behave as specified.
- Quaternion rotation, interpolation, antipodal handling, extrinsic order and pose time limits are checked.
- File schemas, PLY truncation, concept raw-ToF geometry and independently packed NWP1 CRC are checked.
- Export north/south row orientation, PNG signature and archive contents are checked.
- HTTP routes, failed-build state preservation, explicit import and cross-origin refusal are exercised.
- A real UDP datagram is transmitted to a localhost socket and decoded into the bounded buffer.

## Synthetic experiment

[Reference results](../examples/reference-results.md) are generated by the committed reproduction script. The default model has 37,776 input points, 37,511 accepted points, 265 robust rejections, 9,444 supported cells and 98.375% rectangular-grid coverage. Its approximately 0.019236 m cell-center RMSE describes only the chosen synthetic scene and assumptions.

## Browser verification

Manual checks completed in the local browser on 21 October 2026:

- The WebGL terrain and point-cloud views rendered the reference seabed; relief contours, coverage and intensity coloring responded to view changes.
- Changing cell size from 0.50 to 0.60 m rebuilt the grid, and the section slider selected a new northing row.
- Clicking a relief cell displayed its coordinates, elevation, four supporting returns and sampling proxy.
- The CSV file chooser imported the 2,400-point fixture. The resulting 0.60 m grid had 500 supported cells and 2,385 accepted returns.
- The export button downloaded a valid nine-member ZIP, with no archive corruption.
- The synthetic sender delivered 37,776 points in 1,181 UDP datagrams, with zero invalid packets and zero sequence gaps; buffered capture reconstructed the full survey.
- Desktop (1,440 by 1,100) and phone (390 by 844) layouts were inspected. The phone document had no horizontal overflow; the map remained usable and opens above the controls on narrow displays.
- The reference survey and default 0.50 m settings were restored. A [workbench screenshot](assets/workbench.png) records the final terrain view.

These are manual functional checks, not an automated browser regression suite. Browser JavaScript syntax also passed `node --check`.

## Not established

Physical range accuracy, map uncertainty, vehicle pose quality, optical/refraction calibration, navigation-grade outputs, vendor protocol support, lossless mission recording, cloud deployment readiness and hardware fault behavior remain unverified. No measured dataset is included. Display quality and synthetic numerical agreement must not be represented as sensor validation.
